# Озвучка презентации

Голос сгенерирован офлайн движком VoiceStudio (OmniVoice, `k2-fsa/OmniVoice`):
голос диктора задан описанием «male, middle-aged, low pitch», затем все слайды
клонированы с одного референса (`voice_ref.mp3`), поэтому тембр одинаковый.

| Файл | Что это |
|---|---|
| `01.mp3` … `14.mp3` | голос по слайдам |
| `narration_timed.mp3` | вся дорожка, выровненная по таймлайну сценария (5:38) — класть в монтаж с 0:00 |
| `narration_full.mp3` | весь текст подряд с паузами 1,2 с (4:31) |
| `durations.json` | длительность голоса каждого слайда |

Субтитры к таймлайну — `../subtitles.srt`. Пересобрать: `python presentation/tools/voice_omnivoice.py [NN ...]`.
